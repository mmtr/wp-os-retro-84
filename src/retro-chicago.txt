; OS Retro Chicago: glyph source for build-fonts.mjs.
; A heavy system face: vertical stems two pixels wide, horizontals one.
;
; Format
;   key value            font metadata; sizes are in pixels.
;   glyph U+XXXX <adv>   starts a glyph. <adv> is the advance width in pixels;
;                        anything after it is a comment (the character).
;   mark <name> [bias]   an accent; build-fonts.mjs places it over a base letter
;                        to make the Latin-1 accented letters. "<name>.cap" is the
;                        variant used over capitals. bias (left/right) breaks ties
;                        when the mark cannot sit exactly centred.
;   # and .              one text row per pixel row: "#" is ink, "." is blank.
;                        Column 0 is the glyph origin; rows may be shorter than
;                        the advance. Keep a blank column on the right for spacing.
;   ------               the baseline. Rows above it are counted up from it (the
;                        last one rests on the baseline); rows below are descenders.
;   ; text               a comment.
;
; To fix a glyph, edit its rows and rebuild: node src/build-fonts.mjs
